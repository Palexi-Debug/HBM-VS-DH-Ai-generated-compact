# NTM-VS-DH

**Nuclear bombs, built with Mekanism, seen in Distant Horizons, dropped from Valkyrien Skies ships.**

A compact fork of *HBM's Nuclear Tech Mod: Continuum* for **Minecraft 1.20.1 (Forge)**. It keeps only the bombs and removes the rest of the original mod.

## What you get

- **Eight bombs with all their parts:** Little Boy, Fat Man, Gadget, Ivy Mike, Tsar Bomba, N2, Solinium and the Balefire Bomb.
- **Crafted with Mekanism machines.** Every bomb needs plutonium. The big ones need a lot. Beginner bombs (Little Boy, Fat Man, Gadget) are the cheapest.
- **Mekanism radiation.** The fallout contaminates the whole blast zone with real Mekanism radiation. Tooltips show Sv/h and the real weight of each bomb.
- **Distant Horizons.** The mushroom cloud is visible from far away. Quality levels LOW / MEDIUM / HIGH / HIGH_PLUS, chosen automatically.
- **Bomb Drop Rack.** Hang a bomb under it, send a redstone signal, the bomb falls. On a Valkyrien Skies ship it keeps the ship's speed. Bomb masses follow the real values.
- **Clean.** No HBM ores, structures, meteors, hostile mobs, mob drops, gases, pollution, advancements, keybinds or movement.

## Requirements

- **Mekanism** (required)
- **Distant Horizons** (optional)
- **Valkyrien Skies** (optional)

## Good to know

- The mod id is `hbm`: it **cannot** run together with the original NTM Continuum.
- Missiles are still in the code but disabled. Set `missiles=true` in `config/hbm_bombs.properties` to show them in the creative tab.
- Tested together with C2ME, ParCool 4.x and Create in the author's modpack.
- The mod checks for new versions and shows a notice in the mod list.
